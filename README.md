# 🎬 Bootcamp Group 1 - Backend (Movie App)

This is the **backend** of the Movie App developed by **Bootcamp 2025 Group 1**. It provides a RESTful API for managing **movies** and **genres**.  
The application is built using **ASP.NET Core** and **PostgreSQL**.

---

## 🚀 Technologies Used

- **ASP.NET Core 8** – Web API framework
- **PostgreSQL** – Relational database
- **Npgsql** – .NET data provider for PostgreSQL
- **Swagger (Swashbuckle)** – API documentation and testing
- **AutoMapper** – Object-object mapping
- **Autofac** – Advanced dependency injection container

---

## 🛠️ Getting Started

### ✅ Prerequisites

- [.NET 8 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)
- [PostgreSQL](https://www.postgresql.org/download/)
- Optional: [DBeaver](https://dbeaver.io/) or **PgAdmin** for database inspection

---

### ⚙️ Setup Instructions

1. **Clone the repository:**

   ```bash
   git clone https://github.com/katarina819/bootcamp2025Grupa1Backend.git
   cd bootcamp2025Grupa1Backend

   
2. Run the application:
   dotnet run

3. Open Swagger UI to test the API:

   https://localhost:7123/swagger

   or

   http://localhost:5244/swagger
